# SWEAT440 Brand Law

This document is the authoritative brand rule set for all agents and humans producing SWEAT440 content. Rules here are non-negotiable. When in doubt, follow the law.

---

## Brand Name

- Always written: **SWEAT440** — all caps, no spaces, no hyphen
- Never: Sweat440, sweat440, Sweat 440, SWEAT 440

---

## Forbidden Words and Replacements

| Never use | Use instead |
|-----------|-------------|
| HIIT | "strength-based training" or "circuit training" |
| corporate | "our team" / "our experts" / "our programming team" |
| get | rephrase the sentence entirely |
| em dash (—) | rephrase or use a comma/period |

---

## Positioning Anchor

- Tagline: **#NeverLate**
- Core concept: a class starts every 10 minutes — no appointment, no waiting, never late
- This should be the default hook for acquisition copy

---

## Typography

| Use | Where |
|-----|-------|
| **Oswald** — ALL CAPS, italic | Headers and display text |
| **Open Sans** | Body copy, captions, labels |

Never mix in other typefaces without explicit approval.

---

## Color Palette

| Role | Hex |
|------|-----|
| Primary | `#00A3E0` |
| Shade — light | `#99DAF3` |
| Shade — mid | `#0084B5` |
| Shade — pale | `#D2EFFF` |
| Digital only (never print) | `#00FFC2` |
| Callouts / CTAs | `#DDFF00` |

`#00FFC2` is digital-only — do not specify it for print or physical signage.
`#DDFF00` is a high-attention color reserved for calls to action and callout labels.
