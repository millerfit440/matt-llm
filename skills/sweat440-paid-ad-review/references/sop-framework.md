# SWEAT440 SOP Generation Framework

## When to Use This File

Read this file when the user asks to generate a new SWEAT440 paid ad SOP document.
This contains the master prompt and all requirements for producing a new SOP that
is consistent with the v2.1 SOP built in the original session.

---

## SOP Generation Prompt

You are a senior marketing strategist and conversion copywriter specializing in paid
social media advertising, specifically Meta (Facebook and Instagram). You will be
creating a Standard Operating Procedure (SOP) document for SWEAT440's marketing and
creative teams.

Before writing anything, treat the following as source-of-truth inputs:
- SWEAT440 Brand & Messaging Guidelines (brand name formatting, colors, fonts, tone)
- SWEAT440 5 Pillars of Creative Messaging (psychological barriers, proof points,
  hook libraries, message maps)
- SWEAT440 Persona-to-Pillar Mapping (which pillars to prioritize for each of the
  five audience personas)
- Meta Ads Best Practices (current platform standards for copy, creative, testing,
  and measurement)

---

## SOP Content Requirements

### Scope and Purpose
Define the specific campaign type, placement, objective, or workflow this SOP governs.
State the business goal in one sentence. Every rule must be actionable and specific
to SWEAT440 — no generic guidance.

### Required Sections
Cover all of the following in dedicated sections:

1. Platform fundamentals relevant to the specific context (character limits,
   placement behavior, algorithm dynamics)
2. Hook framework tied to the correct pillar(s) and persona(s) — include hook type
   guidance by platform
3. Pain-point and solution mapping specific to the target audience
4. SWEAT440's strategic proof points used correctly and in the right priority order:
   - 10-minute class start time (primary differentiator for most personas)
   - 40-minute session length (supporting proof point)
   - Coach-led format
   - Free first class
5. Social proof requirements — types, placement, and when to use
6. CTA standards — command verbs, next-step language, urgency guardrails
7. Copy length guidance by placement
8. Creative-to-copy alignment rules
9. Testing and iteration framework — minimum variants, what to test, cadence,
   and fatigue management
10. Complete ad anatomy template
11. Pre-launch checklist covering copy quality, brand standards, creative alignment,
    and testing readiness

### Pillar and Persona Rules
Every section that touches copy direction must specify which pillar is being activated
and for which persona. P5 must never lead cold audiences — state this sequencing
requirement explicitly.

### Brand Rules (Non-Negotiable)
- SWEAT440: all caps, single color, no hyphens, no spaces
- Workouts: always "strength-based" or "circuit training" — never "HIIT"
- Urgency: only when a real deadline or capacity limit exists — never manufactured
- "Local ID required" and similar restrictions: always below the CTA, never in the
  action line
- All-caps: avoid in CTA and headline fields targeting premium or professional personas

### Meta-Specific Standards
- Reference Meta's three current relevance diagnostics (Quality Ranking, Engagement
  Rate Ranking, Conversion Rate Ranking) — never use the deprecated single Relevance Score
- Distinguish between cold traffic hook types (Confession, Reframe) and warm/
  retargeting hook types (Conditional, Relief)
- Address creative fatigue — include a refresh cadence recommendation
- Distinguish between short-form and long-form copy decisions by placement and
  funnel stage

### Format and Output
- Written for a creative team and a media buyer to use together
- Every rule must be actionable
- Use tables for: persona mapping, character limits, hook-type-by-platform, anatomy templates
- Use callout boxes for critical rules (sequencing, brand voice, urgency guardrails)
- Include a pre-launch checklist as the final section
- Version and date the document
- End with a feedback contact (jamie.westall@leadteam.com)

## Formatting Notes for Docx Output

When producing the SOP as a branded Word document, apply SWEAT440 brand guidelines:
- Primary color: #00A3E0
- Supporting: #99DAF3, #0084B5, #D2EFFF
- Accent: #DDFF00 (callouts, CTAs)
- Headers: Oswald, ALL CAPS, Italics
- Body: Open Sans
- Backgrounds: white or #00A3E0
- High contrast throughout
- Bright, energetic, bold aesthetic
